# The Lost Barn

So, This is a RPG game made on godot made for Third Space YSWS. Well, this is a complete project.

This is a type of advanture game. The story goes like, our cow is lost and we have to find it. The chicken tells us to go to the jungle to find the cow. There are Magical Stones along the way.

## How to Play

WASD — Move

Space — Attack

## Objective

Player have to find all the magical stone and kill the boss to rescue the cow.

## Installation
Clone the repository:

git clone https://github.com/gunjit-gyawali/The-Lost-Barn
import game to godot
