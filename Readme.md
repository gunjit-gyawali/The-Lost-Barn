# The Lost Barn

So, this is an RPG game made on godot made for Third Space YSWS. Well, this is a complete project.

This is a type of adventure game. The story goes like, our cow is lost, and we have to find it. The chicken tells us to go to the jungle to find the cow. There are Magical Stones along the way.

## How to Play

WASD — Move

Space — Attack

## Objective

The player has to find all the magical stones and kill the boss to rescue the cow.
